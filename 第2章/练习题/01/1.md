# 建立并运行由Kernighan 和Ritchie 编写的著名的“hello, world”程序：
```
#include <stdio.h>

int main(void)
{
  printf("hello, world\n");
}
```
# 在编译时是否有警告信息？如果有，需要如何修改呢？

如果使用C99及以上标准：
> *hello.c文件所在目录*>gcc -O -Wall -W -pedantic -std=c99 -o hello hello.c

那么编译将会正常通过，不会有警告信息。

如果使用C89标准：
> *hello.c文件所在目录*>gcc -O -Wall -W -pedantic -std=c89 -o hello hello.c

编译器会报以下警告：
>hello.c: In function 'main':
>hello.c:6:1: warning: control reaches end of non-void >function [-Wreturn-type]
>    6 | }
>      | ^

**解释：**
main声明为返回 int（非 void），但编译器发现存在一条执行路径——正常执行到函数末尾第 6 行的 }——没有 return 语句。这样函数“执行到结尾”时返回值是未确定的，所以 -Wreturn-type 发出警告。

**关于两个标准的关键区别：**
C99 及以后：
标准明确规定，如果 main 执行到末尾，等同于执行 return 0;。所以编译器知道返回值是 0，不会警告。

C89/C90：
标准没有这条规定。main 正常执行到末尾时，返回给宿主环境（操作系统）的值是未定义的（undefined）。严格来说，C89 下不写return的int main是不规范的，编译器因此给出警告。

**修改：**
在 main 函数末尾添加 return 语句：
`#include <stdio.h>`

`int main(void)`
`{`
`  printf("hello, world\n");`
`  return 0;`
`}`

编译成功后会在同目录下生成一个hello.exe文件，使用以下命令：
> *hello.exe文件所在目录*>hello.exe

即可看到输出：
> hello, world
