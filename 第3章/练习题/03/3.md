# 说明下列每对scanf 格式串是否等价？如果不等价，请指出它们的差异。
# (a) "%d"与" %d"。
# (b) "%d-%d-%d"与"%d -%d -%d"。
# (c) "%f"与"%f "。
# (d) "%f,%f"与"%f, %f"。

(a)等价
因为 %d 本身就会跳过前导空白，所以格式串开头再写一个空格是多余的。两者都会跳过前导空白后读一个整数。

(b)不等价
第二个格式在 %d 和 - 之间、以及第二个 %d 和 - 之间允许出现空白；第一个格式不允许。

(c)不等价
"%f" 只读取浮点数，数字后面的空白会留在输入流中。
"%f " 在读完浮点数后，还会继续匹配并消耗后续空白，直到遇到非空白字符或文件结束。

(d)等价
第二个格式中逗号后的空格是多余的，因为第二个 %f 本身就会跳过前导空白；而且格式串中的空白可以匹配零个或多个空白。
