# 下面的printf 函数调用产生的输出分别是什么？
# (a) printf("%6d,%4d", 86, 1040);
# (b) printf("%12.5e", 30.253);
# (c) printf("%.4f", 83.162);
# (d) printf("%-6.2g", .0000009979);

**·代表空格：**
(a)····86,1040

(b)·3.02530e+01
标准C对指数部分要求：e 符号 至少两位十进制数字（不足用0填充）

(c)83.1620

(d)1e-06·
printf 默认不是“直接舍去”，而是按四舍五入处理：保留两位有效数字时，要看第三位有效数字。
